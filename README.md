# Lab-9-Image-Preprocessing-and-Segmentation


This demonstrates an image processing pipeline for detecting metal studs on tires using computer vision techniques, combining multiple image analysis methods to classify tire types.

### Technical Details

Image Preprocessing	- Comprehensive image transformation techniques: resizing, grayscale conversion, masking
Feature Detection	- Connected component analysis to identify potential tire studs
Classification Logic -	Rule-based decision making using morphological properties and count thresholds
